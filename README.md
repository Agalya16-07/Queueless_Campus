# QueueLess Campus
Run: copy the `queueless` folder to `htdocs` (XAMPP) or run `php -S 0.0.0.0:8000` inside it.
- Students: http://localhost:8000/index.html
- Staff: http://localhost:8000/admin.html  (default password in api/db.php: admin123)
The SQLite database is created automatically in `data/`. Make sure `pdo_sqlite` is enabled in php.ini.
